ABDELMAWLA OMARA PORTFOLIO

This is a static portfolio website. It has no database, login, tracking,
form submission, or stored visitor data. Contact buttons open WhatsApp in
a new tab, and the call link opens the visitor's telephone app.

PUBLISH TO CLOUDFLARE PAGES
1. In Cloudflare, open Workers & Pages.
2. Create a Pages project with Direct Upload.
3. Upload this folder, keeping index.html at the top level.
4. Test the temporary pages.dev address.
5. Add a custom domain only after the preview is correct.

FUTURE EDITS
- index.html: text, links, and page structure
- styles.css: colors, layout, and design
- script.js: navigation and scroll animation
- assets/: profile image and project preview

The _headers file configures security headers on Cloudflare Pages.
Keep it in the publish folder. Do not add passwords, keys, or private
client documents to this static website folder.
